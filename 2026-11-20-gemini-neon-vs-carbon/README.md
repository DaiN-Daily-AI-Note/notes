# 2026-11-20 · 구글 네온 vs 카본, 같은 숙제를 직접 시켜 봤다

다인 쇼츠 "구글 네온, 카본보다 약 60% 싸다? 직접 돌려 봤다"(2026-11-20)에 쓴 시험 파일 전부입니다.
같은 숙제를 여러분의 Antigravity(또는 다른 AI 코딩 도구)에서 그대로 돌려 보고, 같은 채점기로 채점할 수 있습니다.

## 무엇을 했나
- 작은 가계부 저장소 `ledger-tools`에 숙제 2개를 냈습니다. A: 시험 3개가 실패하는 버그 고치기, B: README에 적힌 월별 요약 기능 만들기.
- Antigravity에서 Gemini 4 Neon과 Gemini 4 Carbon에 **같은 문장**으로 모델마다 2번씩 시켰습니다(생각 단계 high, 새 대화, 개입 0번).
- 모델이 볼 수 없는 숨은 검사 10개로 채점하고, 미리 적어 둔 규칙(`DESIGN.md`)으로 판정했습니다.

## 결과 (자세한 표는 `results/RESULTS.md`)
| | 네온 | 카본 |
|---|---|---|
| 숙제 정답(숨은 검사) | 4번 모두 만점 | 4번 모두 만점 |
| 걸린 시간 | 카본의 0.53배(A) · 0.56배(B) | — |
| 숙제 한 번 값(쓴 토큰 × 11월 API 값) | 카본의 0.80배(A) · 0.91배(B) | — |

판정: 품질 같음 + 네온이 더 빠름. 비용은 네온이 약 15% 낮게 나왔지만 미리 정한 기준(20%)에 못 미쳐 "덜 든다"고 판정하지 않았습니다.

## 파일
| 파일 | 내용 |
|---|---|
| `ledger-tools/` | 숙제 저장소(처음 상태: 시험 3개 실패) |
| `PROMPTS.md` | 붙여 넣은 문장 2개와 순서 |
| `DESIGN.md` | 사전 등록한 설계: 지표, 판정 규칙, 판정이 틀릴 수 있는 길과 막는 장치 |
| `lab.py` | 폴더 만들기(`new`) · 채점(`grade`) · 토큰 읽기(`tokens`) · 판정(`decide`) · 채점기 자기 시험(`selftest`) |
| `grader/hidden_checks.py` | 숨은 검사 10개 |
| `grader/cases/` | 채점기를 속이려는 사례 7개(시험 고치기, 건너뛰기, 무한 루프 등) |
| `results/` | 채점 기록, 토큰 합계, 모델이 만든 코드 스냅숏, 판정 결과 |

## 따라 하기
파이썬 3.10 이상과 git만 있으면 됩니다(추가 설치 없음).

```bash
python3 lab.py selftest
```

```bash
python3 lab.py decide
```

첫 줄은 채점기가 속임수 사례를 제대로 잡는지 확인하고, 둘째 줄은 올려 둔 기록으로 판정을 다시 냅니다.
직접 시키려면 `PROMPTS.md` 순서대로 하세요. 이미 있는 `ka`~`kd` 대신 다른 두 글자(예: `za`)를 쓰면 됩니다.

## 한계
- 쉬운 파이썬 숙제 2개 × 모델마다 2번뿐입니다. 둘 다 만점이라 **어려운 일에서 품질 차이가 나는지는 이 시험으로 모릅니다.**
- 시간은 사람이 시계로 쟀습니다.
- 값은 Antigravity 대화 기록의 토큰 수에 구글 API 값을 곱한 계산입니다. Antigravity는 구독이라 실제 청구액이 아닙니다. 출력 토큰에 생각 토큰이 들어간다는 것은 추정입니다.
- 카본은 숙제 A에서 시험을 스스로 더 써서 그만큼 시간·토큰이 늘었을 수 있습니다.
- 숙제 폴더에 이전 준비 단계의 `.pytest_cache`(실패한 시험 이름 3개가 적힌 숨김 폴더)가 남아 있었습니다. 네 번 모두 똑같이 들어 있어 두 모델 비교에는 같은 조건이지만, 모델이 그 파일을 읽었다면 어떤 시험이 실패하는지 미리 알 수 있었습니다. 2026-11-19 공개 준비 중 발견했고, 이 저장소의 `ledger-tools/`에서는 뺐습니다. 대화 기록을 보면 네 번 모두 모델이 폴더 목록에서 이 폴더 이름은 봤지만, 실패 목록 파일(`lastfailed`)을 연 흔적은 없습니다.
- 숨은 검사를 여기 공개했으므로, 이 숙제는 앞으로 "모델이 본 적 없는 시험"으로는 쓸 수 없습니다.

## 안전
- 표준 라이브러리만 씁니다. 인터넷 접속이 없습니다.
- **`lab.py grade`와 `selftest`는 채점할 폴더의 파이썬 코드를 실제로 실행합니다**(따로 띄운 프로세스, 60초 제한). AI가 쓴 코드를 실행하는 것이니, 내용을 모르는 폴더는 채점하지 마세요.
- `lab.py new`는 `~/Studio/ledger-tools-<두 글자>` 폴더를 만들고 그 안에서 `git init`을 합니다. `lab.py tokens`는 내 컴퓨터의 Antigravity 대화 기록(`~/.gemini/antigravity/brain`)을 읽기만 합니다.
- 대화 기록 원본과 대화 ID는 올리지 않았습니다. 토큰 합계 숫자만 있습니다.
- 받은 파일은 **공식 주소 https://github.com/DaiN-Daily-AI-Note/notes** 에서만 받으세요.
- 파일 지문(SHA-256): `lab.py` = `9ef832af9c080c38a9dbaa319cf5ad3c28f82d99d68bc3eeb7b0211b91b43d8b` · `grader/hidden_checks.py` = `4efcd5a227b0d667c605f5f3593eaf61d07e05d7b89c41833c4f4f8bf5487ff4`
  - 맥/리눅스: `shasum -a 256 lab.py` · 윈도우: `certutil -hashfile lab.py SHA256`
