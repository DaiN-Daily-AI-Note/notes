# 붙여 넣은 문장과 순서

세션은 1 → 2 → 3 → 4 순서로 하나씩 했습니다. 폴더는 `python3 lab.py new <두 글자> <모델>`로 실행마다 새로 만듭니다(기본 위치 `~/Studio/ledger-tools-<두 글자>`).

| 세션 | 폴더 | 모델 (Antigravity, 생각 단계 high) |
|---|---|---|
| 1 | `~/Studio/ledger-tools-ka` | Gemini 4 Neon |
| 2 | `~/Studio/ledger-tools-kb` | Gemini 4 Carbon |
| 3 | `~/Studio/ledger-tools-kc` | Gemini 4 Carbon |
| 4 | `~/Studio/ledger-tools-kd` | Gemini 4 Neon |

## 세션 하나의 순서
1. 그 폴더를 열고 **새 대화**를 시작, 모델을 고른다(생각 단계는 건드리지 않음).
2. 시작 시각을 적고 과제 A 문장을 그대로 붙여 넣는다.
3. 모델이 멈추면 끝 시각을 적고 채점한다: `python3 lab.py grade ka A --start 20:47:00 --end 20:49:45 --interventions 0`
4. **같은 대화**에서 과제 B 문장을 붙여 넣고, 끝나면 같은 방식으로 채점한다(`grade ka B …`).
5. 네 세션이 끝나면 `python3 lab.py decide`.

## 과제 A
```
테스트가 3개 실패해요. 원인 찾아서 고쳐 주고, 다 통과하는지 확인해 줘.
```

## 과제 B
```
README '할 일'에 있는 월별 요약 기능 만들어 줘. 테스트도 같이 추가해 줘.
```

## 지킨 것
- 문장은 글자 하나도 바꾸지 않고, 앞뒤에 말을 덧붙이지 않았습니다.
- 대화에 모델 이름이나 "시험·비교·실험" 같은 말을 쓰지 않았습니다.
- 모델이 허락만 물으면 `네`(개입 0번), 방식을 물으면 `알아서 판단해 줘`(개입 1번). 실제로는 8번 모두 개입 0번이었습니다.
- 한 번이 30분을 넘으면 중단, 할당량·속도 제한 오류가 뜨면 그 세션은 끝(재시도 없음).
